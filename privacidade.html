Quem é o controlador

O tratamento é feito por pessoa física, no Brasil, em equipamento próprio, sobre contas das quais é titular. Não há servidor, não há hospedagem e não há banco de dados remoto.

English

Who the controller is

Processing is carried out by an individual, in Brazil, on their own equipment, over accounts they own. There is no server, no hosting and no remote database.

02
Português

Dados obtidos do TikTok

Com o escopo user.info.basic, o programa lê o identificador da conta e o nome de exibição. Serve para uma coisa só: confirmar que o rascunho vai para a conta certa antes de enviar o arquivo.

O programa não lê vídeos, estatísticas, comentários, mensagens diretas, lista de seguidores nem qualquer conteúdo de outras pessoas. Os escopos que dariam esse acesso não foram solicitados.

English

Data obtained from TikTok

With the user.info.basic scope, the program reads the account identifier and display name. This serves one purpose: confirming the draft goes to the correct account before the file is sent.

The program does not read videos, statistics, comments, direct messages, follower lists or any content belonging to other people. The scopes that would grant such access were not requested.

03
Português

Dados enviados ao TikTok

Um arquivo de vídeo MP4 e o texto que o acompanha, ambos produzidos localmente. Nada mais é transmitido.

O envio usa o método push_by_file: os bytes vão direto da máquina para a TikTok. Nenhum arquivo é hospedado em endereço público e nada do sistema fica exposto na internet.

English

Data sent to TikTok

An MP4 video file and the accompanying text, both produced locally. Nothing else is transmitted.

Upload uses the push_by_file method: bytes go straight from the machine to TikTok. No file is hosted at a public address and no part of the system is exposed on the internet.

04
Português

Como as credenciais são guardadas

Os tokens ficam cifrados pela API de Proteção de Dados do Windows (DPAPI), amarrados à conta de usuário da máquina. Copiar o arquivo para outro computador não o torna legível.

Nenhum token aparece em código-fonte, em arquivo versionado, em log, em nome de arquivo ou em linha de comando visível. Há verificação automatizada que falha a construção se uma credencial for gravada em local versionável.

English

How credentials are stored

Tokens are encrypted by the Windows Data Protection API (DPAPI), bound to the machine's user account. Copying the file to another computer does not make it readable.

No token appears in source code, in a versioned file, in a log, in a file name, or in a visible command line. An automated check fails the build if a credential is written to a versionable location.

Português

Seus direitos

Pela LGPD, o titular pode confirmar a existência de tratamento, acessar, corrigir, portar e eliminar seus dados. Como o titular e o operador são a mesma pessoa, o exercício é imediato:

  • Revogar — TikTok, Configurações, Segurança e permissões, Gerenciar permissões de apps.
  • Eliminar — apagar o cofre em %LOCALAPPDATA%\afiliado\. Isso remove todos os tokens de uma vez.

Revogar ou apagar interrompe imediatamente qualquer envio.

English

Your rights

Under Brazil's LGPD, the data subject may confirm processing exists, access, correct, port and delete their data. As the subject and the operator are the same person, exercise is immediate:

  • Revoke — TikTok, Settings, Security and permissions, Manage app permissions.
  • Delete — remove the vault at %LOCALAPPDATA%\afiliado\. This erases all tokens at once.

Revoking or deleting immediately stops any upload.

Português

Retenção

Tokens e identificador ficam enquanto a autorização existir. Revogada a autorização, deixam de funcionar e são apagados na execução seguinte. Os vídeos produzidos e o registro de estado permanecem na máquina até que o operador os remova.

English

Retention

Tokens and the identifier are kept while authorization exists. Once revoked, they stop working and are deleted on the next run. Produced videos and the state record remain on the machine until the operator removes them.
